# Происхождение

Откуда взялось то, что входит в Aim Trainer, и на каком основании. Видно
только то, что есть в самом репозитории; личных данных правообладателя
здесь нет и не будет. Пополняется с каждой чужой частью (`CLAUDE.md`,
«Открытость, лицензия, данные»).

## 1. Правообладатель и репозиторий

- Автор — `dpsmpx` (аккаунт GitHub); все 39 коммитов на 13 октября 2026
  подписаны им.
- Репозиторий `dpsmpx/AIM_Trainer_pas` — публичный, создан 5 июля 2026;
  первый коммит `9857adf` — `LICENSE` (GNU GPL v3) и заголовок README
  (D-03).
