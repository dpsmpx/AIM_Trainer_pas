# Отладочные сборки AIM Trainer

Ветка только со сборками для проверки у автора на Windows; в `main` не
вливается (решения D-23 и D-34 в `docs/direction/DECISIONS.md` ветки
`main`). Скачать: «Code» → «Download ZIP».

- `AimTrainer/` — программа (C++-версия): из какого коммита —
  `AimTrainer/BUILD.md`, как запустить и что проверить —
  `AimTrainer/README.md`.
- `AimProbes/` — замерщики ввода восьми библиотек (`docs/LIB_PROBES.md`):
  из какого коммита — `AimProbes/BUILD.md`.
