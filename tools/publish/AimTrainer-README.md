# DP AIM Trainer — сборка для Windows

Отладочная сборка C++-версии для проверки у автора (D-23, D-34 в
`docs/direction/DECISIONS.md`). Из какого коммита и какой ветки —
`BUILD.md` рядом: решения, сценарии и устройство — в той ветке, пока она
не влита в `main`.

## Запуск

1. Скачать ветку: «Code» → «Download ZIP», распаковать.
2. Запустить `AimTrainer/AimTrainer.exe`. Каталог `fonts/` должен лежать
   рядом с EXE: без него программа скажет, какого файла нет, и закроется.

Файлы игрока — в `%APPDATA%\AimTrainer\` (профили, история, экспорт CSV,
реплеи рекордов в `replays\`); «Настройки» → «Открыть папку сохранений»
открывает её, строка «Папка: …» — выбрать другую, сохранения скопируются
туда (D-33, D-35). Файлов Pascal-версии программа не читает: форматы
файлов новые (D-38).

## Свои темы

Файл `themes\ИМЯ.ini` в папке сохранений — своя тема (D-44), выбор —
«Настройки» → «Тема». Строка — `ключ=#RRGGBB` или `#RRGGBBAA`
(последние две цифры — непрозрачность); `base=dark`, `neon` или
`minimal` — встроенная тема, откуда берутся незаданные цвета; строки с
`;` в начале — пояснения. Например:

```
base=dark
background=#1A2A40
accent=#FF9020
target_left=#40FF60E0
```

Ключи:

- `background` — фон окна;
- `accent` — акцент: разделы справки, полоса прокрутки, график, рамки;
- `text` — основной текст;
- `text_dim` — второстепенный текст;
- `label` — подпись у пары «подпись: значение»;
- `gold` — рекорды, достижения, рамка уведомления;
- `good` — «Начать замер», «▶», плашка реплея;
- `warn` — предупреждение: «Фальстарт»;
- `target_left` — цель для ЛКМ;
- `target_right` — цель для ПКМ;
- `signal` — замер на цвет: окно после смены цвета;
- `bomb` — бомба;
- `bomb_cross` — крест на бомбе;
- `hud` — ячейки панели замера;
- `overlay` — плашки поверх замера;
- `trail` — след курсора;
- `wave` — волна попадания;
- `flash_hit` — вспышка точного попадания;
- `flash_bomb` — вспышка подрыва;
- `dim` — затемнение под панелью;
- `panel` — панель;
- `panel_border` — рамка панели;
- `row` — подложка строки панели;
- `button` — светлая кнопка «−»/«+»;
- `button_text` — текст на светлой кнопке;
- `control` — кнопка-действие;
- `toast` — фон уведомления;
- `toast_text` — текст уведомления;
- `plate` — плашка-превью набора;
- `graph` — фон графика;
- `grid` — сетка графика;
- `particles` — частицы фона меню;
- `preset_color` — кнопка «Реакция на цвет»;
- `preset_classic` — кнопка «Классика»;
- `preset_dual` — кнопка «Две кнопки»;
- `preset_tracking` — кнопка «Слежение»;
- `preset_flick` — кнопка «Флик»;
- `preset_custom` — кнопка «Свой набор».

## Что проверить

Сценарии `docs/MANUAL_CHECKS.md` ветки из `BUILD.md`, прежде всего те, что видны
только на Windows:

- 4 — FPS на HUD не ниже частоты монитора, без провалов (D-32); с
  `--debug-title` после замера в заголовке — сводка кадров: 99 % не дольше
  запаса (D-41);
- 9 — средняя реакция со звуком и без — одинаковая (AUD-06);
- 21 — запуск `AimTrainer.exe --debug-title`: в заголовке окна после
  щелчков — «время из сырого ввода» (D-24);
- 23, 25, 26 — файлы игрока, шрифт, звук;
- 27 — открыть и сменить папку сохранений;
- 28 — замер на цвет; 30 — окно при масштабе экрана 150 %;
- 31 — справка листается стрелками, колёсиком и полосой прокрутки;
- 32 — реплей рекорда из «Рекордов наборов»; 33 — конструктор «Свой
  набор»; 34 — замер без интерфейса и без записи реплеев; 35 — шрифты
  Condensed и Mono, ничего не обрезано (`AimTrainer.exe --text-check` —
  не поместившиеся надписи в журнал); 36 — темы и своя тема (ниже).
