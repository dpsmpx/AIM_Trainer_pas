# Ручные проверки

Сценарии, которыми проверяется правка кода (D-07): в облачной сессии
инструменты для сборки программы на GraphABC пока не настроены. Прогон —
у автора на Windows в PascalABC.NET (`F9` на `AIM_Trainer.pas`). Те же
сценарии — критерий готовности переноса на C++ (D-08). C++-версия
собирается по `docs/BUILD.md`, §1; в сессии её проверяет
`tools/check_cpp.sh` (D-25), а сценарии — то, что видно только на
Windows.

**Что писать в PR:** версия PascalABC.NET («Помощь → О программе»),
версия Windows, номера пройденных и не пройденных сценариев. Правка
кода без прогона — «не компилировалось, сценарии не проходились».

Столбец «сейчас» — состояние Pascal-версии по чтению кода (аудит
`docs/audits/PROJECT_AUDIT.md`), а не по прогону: «✗ AUD-NN» — ожидается
провал из-за находки. Pascal-версия остаётся как есть (D-09), поэтому
для неё «✗» — навсегда; проходить все сценарии обязана C++-версия. Её
файлы профиля лежат в папке пользователя (D-11), а не рядом с
программой; шаги сценариев под неё переписываются на шаге переноса
«Переход».

## Подготовка

- Чистый каталог: удалить `profile*_stats.ini`, `profile*_sessions.csv`,
  `profile*_corrupt_backup.txt`, `export_profile*.csv` рядом с программой.
- Настройки по умолчанию: размер 40, жизнь цели 1000 мс, жизни 15, звук
  включён, тема «Тёмная».
