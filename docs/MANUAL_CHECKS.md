# Ручные проверки

Сценарии, которыми проверяется правка кода (D-07), — критерий готовности
переноса на C++ (D-08): C++-версия обязана пройти их все. Она собирается
по `docs/BUILD.md`, §1; в сессии её проверяет `tools/check_cpp.sh` (D-25),
у автора на Windows — сценарии, а прежде всего то, что видно только на
Windows. Образец — Pascal-версия в `archive/pascal/` (D-28): у автора она
больше не прогоняется, в сессии её запускает `tools/gui.sh ref` (D-26),
итоги — «Эталон под Mono» ниже.

**Что писать в PR:** версия Windows, номера пройденных и не пройденных
сценариев. Правка кода без прогона — «не компилировалось, сценарии не
проходились» или «на Windows не проверялось».

Столбец «сейчас» — что делает образец: по прогону эталона под Mono
16 октября 2026, где он был («прогон»), иначе по чтению кода (аудит
`docs/audits/PROJECT_AUDIT.md`); «✗ AUD-NN» — провал из-за находки.
Образец остаётся как есть (D-09), поэтому для него «✗» — навсегда. У
C++-версии файлы профиля лежат в папке пользователя (D-11, D-30:
`%APPDATA%\AimTrainer\`), а не рядом с программой; шаги сценариев под неё
переписываются на шаге переноса «Переход».

## Подготовка

- Чистый каталог: удалить `profile*_stats.ini`, `profile*_sessions.csv`,
  `profile*_corrupt_backup.txt`, `export_profile*.csv` рядом с программой.
- Настройки по умолчанию: размер 40, жизнь цели 1000 мс, жизни 15, звук
  включён, тема «Тёмная».

## Эталон под Mono — прогон 16 октября 2026

Оригинал — `*.pas` корня (без правок с 23 августа 2026, D-09), PascalABC.NET
4.0.0.3882 под Mono 6.8 в Xvfb (D-26); управление — `tools/gui.sh ref`,
игра — `tools/helpers/ref_bot.py` (D-27). Итоги по сценариям — в столбце
«сейчас» выше; что важно для переноса:

- **Падение на трёх экранах (сценарий 22).** `FillRoundRect(0, 0, W, H, 0,
  0)` — вспышка точного попадания (эффект 4, точность от 95 %), вспышка
  подрыва (эффект 5) и затемнение паузы (`RenderPauseOverlay`): GraphABC
  строит скругление дугами `GraphicsPath.AddArc` нулевого размера, GDI+
  отвечает `InvalidParameter`, исключение не ловится. Код этих мест — от 23
  августа 2026, после него программу никто не собирал (AUD-29).
- **Подтверждены прогоном:** AUD-02, AUD-04, AUD-07 (б), AUD-08, AUD-09,
  AUD-10, AUD-13, AUD-26. Не воспроизвелась за короткий прогон: AUD-18.
  Не проверялись: 8 и 9 (точный замер реакции и звук — только Windows),
  AUD-16 (пауза падает).
- **Пройдены:** 1, 2, 12, 13 (а), 14; 15 — без паузы.

Чем Mono отличается от Windows — не сравнивается:

- текст — libgdiplus и cairo, Consolas подменён DejaVu Sans Mono (D-22):
  он шире, и подписи кое-где не помещаются («Best Avg», «Сбросить по
  умолчанию», подсказка внизу панели настроек);
- частота кадров — ограничитель на 240 под Mono держит 254–276: `Sleep`
  здесь точнее, чем на Windows (AUD-25);
- звук `Console.Beep` под Mono не проверялся.
